# 汇率监控（SGD → MYR）

CIMB Clicks 与 Wise 的新币兑马币汇率监控 App。

## 首次使用
- 允许通知权限。
- 设置 → 后台运行 → “允许后台运行（关闭电池优化）”，否则手机休眠后无法每分钟检查。
- 部分手机（小米/OPPO/vivo/华为等）还需在系统设置里把本 App 设为“自启动”“无限制”。

1.后台服务每 30秒/1分钟/2分钟/5分钟/15分钟检查一次，默认 1 分钟。目标汇率默认 3.18，可选按 CIMB、Wise 或最佳比较。提醒可设响铃、震动，也能跳到系统通知设置换铃声。免打扰时段内不弹提醒，结束后若仍高于目标会立刻提醒。支持开机自启，也能一键发测试提醒。
2.输入任意金额，两家各自显示到账马币和实际汇率。
3.默认金额是 1000 新币。
4.历史只记录 App 自己抓到的数据，有 1小时/24小时/7天/全部的折线图，带目标线和最高/最低/平均。
5.Wise 官方文档，有一个 POST https://api.wise.com/2026Q4/quotes 的接口，文档写明不需要账号或密钥，用于展示汇率和估算。它会返回汇率、总手续费和到账金额，和网页上看到的是同一类数据。同时加了旧版地址 /v3/quotes/ 作备用。
6.首页直接推荐更划算的一家，并显示多收多少马币，另有"当前汇率高于过去24小时多少%"的参考。
7.主题可选跟随系统、白天、黑夜。
8.首页有两个按钮，分别直达 CIMB 和 Wise 页面
